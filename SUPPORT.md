# Support

SignalKit is an early foundation. Next.js and Bun are planned initial targets; no SDK integration is currently claimed to work.

- Search existing issues before opening a bug or feature request.
- Use the issue templates with runtime versions, reproducible steps, and redacted diagnostics.
- Report security concerns using [SECURITY.md](SECURITY.md).
- Follow the [code of conduct](CODE_OF_CONDUCT.md).

Support is best effort by the Tech Inject project team and contributors. There is no funded support program, response SLA, or production reliability guarantee. Provider-account, billing, and destination-dashboard questions may require the provider's own support.

Clearly distinguish local validation, a dispatched request, provider acceptance, and provider-side verification. Do not share credentials or customer data to obtain help.

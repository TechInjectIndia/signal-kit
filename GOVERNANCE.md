# Governance

The Tech Inject project team stewards the project; [@TechInjectIndia](https://github.com/TechInjectIndia) is the initial repository administrator and code owner. Independent review is currently unavailable because only one maintainer account is assigned. SignalKit is maintained as an open-source project under the MIT license.

## Decisions and roles

Contributors propose changes through issues and pull requests. Maintainers review scope, compatibility, security, documentation, and verification before approving and merging changes. Maintainers control repository settings and releases.

Use issues for significant changes to event contracts, provider behavior, framework support, and release policy. Record the decision and its reasoning so others can follow it. Maintainers make the final decision when consensus is not reached; contributors may ask for reconsideration with new evidence.

Maintainer access may be granted after sustained constructive contributions and demonstrated review judgment. The current maintainers approve changes to maintainer access and may revoke access when necessary to protect the project.

## Releases and compatibility

There is no released SDK yet. Future releases should document implemented capabilities, supported runtime versions, breaking changes, and known limitations. Planned support is not verified compatibility. Release and maintenance commitments must be documented before they are promised.

## Contributor rights

No CLA or DCO is currently required. Contributors retain copyright in their work and contribute under the repository license. Disclose relevant conflicts of interest when proposing provider-specific or commercial changes.

See [contributing](CONTRIBUTING.md), [security](SECURITY.md), and [conduct](CODE_OF_CONDUCT.md).

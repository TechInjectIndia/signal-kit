## Try without registry publication

Run the documented builds/checks, then pnpm release:prepare. artifacts/0.1.0-alpha.1 contains seven .tgz files, a bundled browser ESM module, manifest, SHA256SUMS and a safe local installer:

```sh
node artifacts/0.1.0-alpha.1/install-local.mjs /path/to/fresh-consumer
```

The installer refuses to overwrite an existing package.json and applies local SDK package overrides. External dependencies install from the normal registry. This lets a reviewer test actual packages without claiming @techinject registry packages exist.

## Known boundaries

Local/script/transport acceptance is not advertising delivery, matching, attribution or dedup. Host owns verified purchase state, consent, durable outbox and retry. Next global OTel policy/redaction is host-owned and separate from browser categories. Edge/native Python/PHP and other framework adapters remain future. Browser custom work and flush are bounded best effort; disposed work cannot guarantee delivery. Docs/GIF/video use synthetic local recorders, no live customer data.

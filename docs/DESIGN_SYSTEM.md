# Local lab visual foundation

Implementation decision, 2026-10-05; no supplied brand kit. The demo is a local developer fixture, not a commercial storefront or hosted dashboard.

A quiet editorial lab: warm paper, deep green ink, lime action accent; Georgia serif headings and monospace diagnostics using system fonts without external font requests. Plain CSS semantic tokens live in examples/nextjs/app/style.css. No component library or decorative assets. Keyboard focus outlines, native labelled consent checkboxes, semantic headings, responsive single-column layout below 800px. The lab stays noindex. Do not copy its sample checkout into production.

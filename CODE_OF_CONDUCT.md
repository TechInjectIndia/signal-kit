# Code of conduct

Treat contributors and users with respect. Discuss ideas and evidence without personal attacks. Welcome different experience levels, ask clear questions, and give constructive feedback.

Harassment, discrimination, threats, doxxing, unwanted sexual attention, and repeated disruptive behavior are unacceptable. Do not publish another person's private information or sensitive diagnostics.

These expectations apply to project issues, pull requests, discussions, and other project-managed spaces. Maintainers may edit or remove content, lock discussions, warn participants, or restrict participation according to the severity and recurrence of the behavior. Maintainers should explain moderation decisions when doing so does not expose private information.

To report a concern, request a private contact channel from a maintainer without posting sensitive details publicly. A dedicated confidential reporting channel has not yet been established. Maintainers must treat reports discreetly and avoid retaliation; confidentiality cannot be guaranteed on third-party platforms.

The Tech Inject project team maintains these original project norms. See [governance](GOVERNANCE.md).
